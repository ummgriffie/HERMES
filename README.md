HERMES Dashboard — Render Static Site

This is the updated version styled after starsdcollective.com.

Features:
- Clean modern dark design with orange accents
- Interactive HERMES sprite world (click rooms to move agent)
- Compact line graph for equity
- Animated loading bars for market strength (orange = weak, blue = strong)
- Fully mobile responsive (works great as iPhone PWA)
- Signals, Equity, Intel, Recording Studio sections

Deployment on Render.com:
1. Upload these files to your GitHub repo root
2. Create new Static Site
3. Set Publish Directory to "."
4. No build command needed

To use as iPhone app:
- Visit the live URL in Safari
- Tap Share → "Add to Home Screen"
